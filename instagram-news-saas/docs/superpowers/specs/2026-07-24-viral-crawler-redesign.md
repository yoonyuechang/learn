# 바이럴 뉴스 크롤러 리디자인

## 문제
현재 크롤러는 Google News + 한국경제 RSS에서 최신순으로 기사를 긁어옴. 결과적으로 자극적이고 바이럴 tiềm력이 높은 뉴스가 아닌, 일반적인 뉴스만 수집됨. 캡션도 템플릿 기반으로 진짜 콘텐츠가 아닌 빈 문장이 생성됨.

## 목표
- **오늘 날짜 뉴스만** 크롤링 (당일 업로드용)
- **반응이 증명된 소스**에서 크롤링 (감정 자극, 속보, 연예)
- **바이럴 스코어 50 이상** 기사만 AI 분석
- **20줄+ 캡션** with 기승전결 내러티브 (템플릿 없음)

---

## 1. 크롤러 리디자인

### 새 RSS 소스

| 소스 | URL | 카테고리 | 특징 |
|------|-----|----------|------|
| 연합뉴스 | `http://www.yna.co.kr/RSS/news.xml` | 속보 | 한국 최대 속보, 댓글活跃 |
| 비즈워치 | `https://www.bewiz.com/rss/all.xml` | 경제 | 비즈니스 핫이슈 |
| 오마이뉴스 | `https://www.ohmynews.com/rss` | 사회 | 감정 자극형 시민 기사 |
| 프레시안 | `https://www.pressian.com/rss` | 사회/정치 | 심층 보도 |
| 한국경제 | `https://www.hankyung.com/feed/all-news` | 경제 | 유지 |
| Google News | `https://news.google.com/rss?hl=ko&gl=KR&ceid=KR:ko` | 종합 | 속보 |

### 크롤링 로직 변경

```
1. 각 소스에서 최대 15개 기사 크롤링
2. 오늘 날짜 필수 (publishedAt이 오늘이 아닌 것 스킵)
3. 중복 제거 (sourceUrl 기준)
4. og:image 없으면 스킵 (카드 이미지 불가)
5. 휴리스틱 바이럴 스코어 계산
6. 스코어 50 이상만 AI 분석 (Mistral-7B)
7. 상위 5개만 콘텐츠 생성
```

### 오늘 날짜 필터
- `publishedAt`이 오늘 00:00 ~ 23:59 사이인 것만
- 한국 시간 기준 (KST, UTC+9)

## 2. 바이럴 스코어 강화

### 휴리스틱 점수 (0-100)

기본값: 0 (이전: 10)

**강력 감정 키워드 (제목에 있으면 +20)**
```
충격, 속보, 긴급, 경악, 폭로, 파문, 발칵, 날벼락, 실체, 몰카,
사건, 사고, 사망, 살인, 성범죄, 아동, 성추행, 동요, 분노,
비극, 참사, 무고, 억울, 울분, 탄원, 청원
```

**논란/갈등 키워드 (+12)**
```
논란, 반발, 비판, 갈등, 공방, 위법, 위헌, 처벌, 금지, 규제,
기소, 구속, 항소, 유죄, 무죄, 특검, 수사, 기소
```

**공감/궁금증 키워드 (+15, 제목에 있으면)**
```
화제, SNS, 레전드, 실화, 황당, 어이없, 대박,깜놀, 반전, 쇼킹,
월드투어, 콘서트, 컴백, 팬미팅, 아이돌
```

**돈/부동산 갈등 (+8)**
```

**유명인/정치 (+10, 제목에 있으면)**

BTS, 방탄, 아이돌, 연예인, 배우, 가수

**카테고리 보정**
- society: +15
- culture: +12
- politics: +10
- sports: +8
- economy: +5
- tech: +3
- world: +2
- general: 0

**페널티: 뉴스 아닌 것 (-25)**
```
개최, 참여, 선정, 위촉, 임명, 인사, 착공, 기공, 준공, 개원,
개장, 이전, 설립, 협약, MOU, 발전, 앵커

### AI 바이럴 분석 (Mistral-7B)
- 휴리스틱 50 이상인 것만 AI 분석
- AI 점수 0.6 + 휴리스틱 0.4 = 최종 스코어
- 최종 스코어 50 이상만 콘텐츠 생성

## 3. 캡션 생성 — 순차 4단 방식

### 문제
현재 병렬 4방식은 각 단이 독립적이어서 연결성 없고, 8줄 정도만 생성됨.

### 해결
기→승→전→결 **순차** 생성. 각 단이 이전 단락 맥락을 받아서 자연스러운 내러티브.

```
[1단: 기/도입]
- 뉴스 핵심 사실 3-5문장
- 사용자에게 질문 던지기 ("이 소식 보셨어요?")

[2단: 승/전개]  
- 1단 내용 이어서 심화 설명
- 배경, 맥락, 영향 3-5문장

[3단: 전/위기]
- 논란, 갈등, 반발, 문제점
- 반대 의견, 우려 3-5문장

[4단: 결/결론]
- 앞으로 전망, 의미
- 질문 CTA ("이 문제 어떻게 생각하시나요? 🤔💬")
- 팔로우 CTA ("팔로우하면 하루에 두 번, 똑똑해집니다 🍯")
```

각 단 API 호출 시 프롬프트에 이전 단락 포함:
```
이전 단락: {1단 내용}
위 내용을 이어서 작성해주세요.
```

### 해시태그
- 4단 완료 후 별도 API 호출로 해시태그 8-10개 생성
- JSON: `{"hashtags": ["#뉴스", "#속보", ...]}`

### 템플릿 제거
- "전문가들은...", "이 뉴스가 주목받는 이유는..." 같은 템플릿 문장 금지
- 뉴스 내용에 기반한 진짜 콘텐츠만
- 본문 끝에 CTA 2줄 고정

## 4. 카드 이미지

### 현재 상태 (이미 구현됨)
- NotoSansKR Bold (weight 900) 폰트
- 뉴스 사진 배경 + 헤드라인 텍스트 오버레이
- 카테고리 뱃지 제거
- 그라데이션 fallback (이미지 없을 때)

### 유지
변경 없음. 이미 사용자가 원하는 스타일로 구현됨.

## 5. DB 스키마

### 변경 없음
기존 News, Copy, Image 테이블 유지.
`newsImageUrl` 컬럼은 이미 raw SQL로 존재.

## 6. 에러 핸들링

### 크롤러
- RSS 파싱 실패 → 해당 소스 스킵, 다음 소스 진행
- og:image 없으면 → 해당 기사 스킵
- 오늘 날짜 아닌 것 → 스킵

### 캡션 생성
- AI API 실패 → 휴리스틱 기반 캡션 fallback (제목 + 본문 요약 + CTA)
- 4단 중 실패 → 이전 단까지만 사용

---

## 7. 검증 방법

1. 서버 재시작 후 크롤링 실행
2. 크롤링된 기사 중 오늘 날짜 + 이미지 있는 것 확인
3. 상위 3개 기사 콘텐츠 생성
4. 캡션 20줄+ 확인, 템플릿 문장 없음 확인
5. 카드 이미지에 NotoSansKR 폰트 적용 확인
